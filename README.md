# ONKOS File Transfer

Aplicacion para transferir archivos entre computadores mediante IP local.

## Tecnologia
- C#
- Windows Forms
- .NET Framework 4.8
- TCP/IP
- Puerto TCP 5050

## Uso
1. Abrir el programa en ambos computadores.
2. Activar la recepcion en el equipo destino.
3. Escribir la IP del receptor en el emisor.
4. Seleccionar el archivo y enviarlo.

Proyecto de Sistemas ONKOS.
